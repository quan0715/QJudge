# Setting Up a Classroom

From this step onward, operations transition from the administrator to the instructor. Confirm that the top-right user menu displays "Teacher" before creating a course; if it still shows "Student", refer back to [Managing Teacher Qualifications](#/docs/teacher-qualification).

In QJudge, a "Classroom" corresponds to a course, a cohort, or an academic term. Instructors first set up a classroom and then organize student rosters, announcements, and multiple exams within that shared space. This ensures you do not need to re-import students for midterms or finals later in the term.

## Creating This Term's Course

After logging in, instructors arrive at the home page. On first access, "My Classrooms" will be empty.

1. Click **New** at the top of the page.
2. Select **Create Classroom**.
3. Enter a name that clearly identifies the semester and course for your teaching team, such as `Operating Systems 2026`.
4. Briefly describe the purpose in the description field. The description can be updated later; you do not need to paste your entire syllabus here.

![Teacher entering classroom name and description](/docs/images/admin-getting-started/classroom-create.png)

*Figure: Creating a classroom requires only a name; description is optional. Including the academic year or semester in the name helps identify archived courses later.*

Click **Create**, and QJudge will navigate directly into the new classroom. Verify that the title and description are correct. A member count of 0 is normal at this stage; students will be added in the next step.

![Classroom overview page after creation](/docs/images/admin-getting-started/classroom-overview.png)

*Figure: The classroom overview consolidates course information, upcoming exams, and announcements. The member count displayed on the right excludes the classroom owner.*

## Key Areas of a Classroom

Tabs below the header adapt based on user roles. For initial onboarding, familiarize yourself with these three:

- **Overview**: Summarizes upcoming exams and recent announcements.
- **Classroom Members**: Displays current instructors, teaching assistants, and enrolled students.
- **Contest List**: Used to create programming contests and written exams.

You do not need to configure schedules and announcements all at once. Adding your student roster before preparing your first exam ensures roles and permissions are properly aligned.

## Naming Conventions and Section Codes

The system does not require separate course codes, so there is no need to invent complex numbering schemes beforehand. If a single course has multiple sections, include the section in the name (e.g. `Operating Systems 2026 - Section A`). If your institution uses fixed course numbers, include them in the title for convenient searchability by instructors and TAs.
