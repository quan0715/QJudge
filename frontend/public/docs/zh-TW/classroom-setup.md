# 建立教室

從這一步開始，操作身分由管理員交給教師。請先確認右上角使用者選單顯示「教師」，再開始建立課程；若仍顯示學生，請回到[管理教師資格](#/docs/teacher-qualification)。

QJudge 的「教室」可以對應一門課、一個班級或一個學期。教師先建立教室，再把學生名冊、公告與多場考試放進同一個空間。這樣第二次段考或期末考就不必重新整理所有學生。

## 建立這學期的課程

教師登入後會進入首頁。第一次使用時，「我的教室」會是空的。

1. 按頁面上方的「新增」。
2. 選擇「建立教室」。
3. 輸入能讓授課團隊辨認學期與課程的名稱。本例使用 `115 學年度作業系統`。
4. 在描述中簡短寫下課程用途。描述可以之後再修改，不需要把完整課綱貼進來。

![教師填寫教室名稱與描述](/docs/images/admin-getting-started/classroom-create.png)

圖：建立教室只需要名稱，描述為選填。名稱中保留學年度或學期，有助於日後辨認封存課程。

按下「建立」後，QJudge 會直接進入新教室。先檢查頁首名稱與描述是否正確；成員數量為 0 是正常的，下一步才會加入學生。

![新教室建立完成後的概要頁](/docs/images/admin-getting-started/classroom-overview.png)

圖：教室概要集中顯示課程資訊、即將開始的考試與最新公告。右側顯示的成員數不包含教室擁有者。

## 教室裡有哪些區域

頁首下方的分頁會隨角色顯示不同內容。第一次導入先認識以下三個即可：

- 「概要」整理近期考試與公告。
- 「教室成員」讓教師確認目前有哪些教師、助教與學生。
- 「競賽列表」用來建立程式競賽或紙筆考試。

排程、公告與其他設定不必一次完成。先把名冊放進教室，再準備第一場考試，較容易逐步確認權限與資料是否正確。

## 名稱需要包含班級代碼嗎

系統目前不要求另外設定課程代碼，因此不必為了部署預先設計一套編碼規則。如果同一門課有多個班級，可以直接在名稱中加入班別，例如 `115 學年度作業系統 A 班`。學校已有固定課號時，也可以一併放入名稱，方便教師與助教搜尋。
