# 管理教師資格

能登入 QJudge，代表系統已經確認使用者是誰；能建立教室與考試，則代表這個帳號已取得教師資格。這兩件事刻意分開，避免任何使用校園登入或自行註冊的人自動取得授課權限。

這一步由管理員執行。資格確認完成後，管理員會登出，後續操作改用教師帳號。

## 先確認教師已經有帳號

請教師先用單位提供的登入方式進入 QJudge。一般帳密、Google、GitHub 或校園單一登入都可以；登入方式不影響之後的教師資格。

如果管理員在使用者管理中搜尋不到該帳號，先請對方完成一次登入或註冊。不要為了省略這一步而共用管理員帳號。

## 將帳號開通為教師

1. 以管理員帳號登入，從右上角使用者選單進入「使用者管理」。
2. 使用完整帳號或電子郵件搜尋教師。本例搜尋 `wang_teacher`，畫面顯示名稱為王老師、目前角色為學生。
3. 確認帳號與信箱都正確，再按「直接開通教師」。
4. 系統會再次顯示原角色與新角色。確認對象無誤後按「確認」。

![將王老師的角色由學生變更為教師的確認視窗](/docs/images/admin-getting-started/teacher-role-confirmation.png)

圖：角色變更前的最後確認。成為教師後，該帳號就能建立教室並使用教師端管理功能。

完成後，搜尋結果中的角色會改為「教師」。請管理員從右上角使用者選單登出，再由教師使用自己的帳號登入。這個角色交接也代表站台管理工作暫時告一段落。

## 其他開通方式

使用者管理頁也能產生一次性的教師開通連結，適合尚未確定登入方式、或希望由教師自行完成首次登入的情況。連結具有時效性與授權效果，應只傳給已確認身分的教師，不要放在公開公告、課程網站或文件截圖中。

對多數已有 QJudge 帳號的教師而言，直接搜尋帳號並變更角色較容易檢查，也更適合作為第一次導入的主流程。

## 權限仍有下一層

教師資格是平台層級的角色；它讓使用者可以建立自己的教室，但不代表能管理其他教師的課程。教室建立後，授課教師還可以依需要將助教加入個別教室，讓助教只取得該課程所需的權限。
