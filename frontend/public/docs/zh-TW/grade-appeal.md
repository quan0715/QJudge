# 成績申訴

紙筆題考試公布成績後，如果你對某一題的分數或批改評語有疑問，可以直接在該題提出申訴，並在同一段對話中與教師、助教確認。

申訴內容只開放給你與這場考試的管理者，其他學生看不到。本頁附圖使用虛構帳號與考試資料示範。

## 1. 找到要申訴的題目

登入 QJudge，進入課程教室，開啟該場考試，再切換到「作答紀錄」。先確認題目、自己的答案、目前分數與批改評語，找到需要重新檢視的地方。

在該題下方按「提出申訴」。只有成績已公布、而且已有分數的紙筆題作答，才會出現這個按鈕。

![在作答紀錄中確認分數與評語，並找到題目下方的「提出申訴」](/docs/images/grade-appeal/01-results.png)

圖：先核對自己的作答與評語，再針對這一題提出疑問。

## 2. 說明申訴理由

在「申訴理由」填入希望重新確認的內容，再按「送出申訴」。建議指出原答案的具體段落，以及你認為可能漏看或需要說明的配分。

例如：

> 我的答案最後一段已寫出 n / 2ᵏ = 1，並推導出 k = log₂ n。評語提到需要補充比較次數，想請助教確認這段推導是否有計入分數，謝謝。

![填寫具體的申訴理由，確認後按「送出申訴」](/docs/images/grade-appeal/02-create.png)

圖：用原作答中的內容說明疑問，方便授課團隊找到需要檢視的地方。

理由不能空白，每則訊息最多 5000 字元，目前只支援文字。送出申訴不會自動改分，仍需由教師或助教檢視。

## 3. 查看回覆與補充說明

送出成功後，畫面會顯示「未結案」，申訴理由也會成為對話中的第一則訊息。之後回到同一題，按「查看申訴」就能繼續閱讀與留言。

按「重新整理留言」取得最新回覆。需要補充時，在「留言內容」輸入文字，再按「送出留言」；新訊息會接在原對話後方，每則都會顯示作者與時間。

![在同一件申訴中閱讀助教回覆，並補充說明](/docs/images/grade-appeal/03-conversation.png)

圖：同一題的討論留在同一件申訴中，不需要重複送件。

目前不會寄送申訴通知郵件，也不會自動更新對話，請主動回到頁面查看。已送出的訊息不能修改或刪除；如果需要更正，請新增一則留言說明。

## 4. 查看結案結果

教師或助教處理完成後，會將申訴標示為「已結案」。你仍可閱讀完整對話，但不能再新增留言，也不能自行重開案件。

![申訴結案後，仍可查看對話與目前成績](/docs/images/grade-appeal/04-closed.png)

圖：這個範例經重新檢視後調整為 8 分；實際結果也可能維持原分，請以授課團隊的回覆與成績頁為準。

申訴畫面的「目前成績」顯示這題最新的分數。關閉申訴視窗後，可以回到作答紀錄確認各題分數與總分。

## 常見問題

### 找不到「提出申訴」按鈕

先確認這是紙筆題考試、成績已公布，而且該題已有分數。如果顯示「查看申訴」，表示這題已經開過案件，請直接進入原對話。仍有疑問時，請聯絡課程教師或助教。

### 同一題可以再開一件申訴嗎？

每份單題作答只能有一件申訴。未結案時可以在原對話補充；已結案後如仍有疑問，請依課程指定的聯絡方式詢問授課團隊。

### 為什麼暫時看不到原本的申訴？

如果教師暫時取消公布成績，學生也會暫停查看申訴與留言。原對話會保留，重新公布後即可再查看。

### 申訴有截止時間嗎？

目前系統沒有獨立的申訴截止時間設定。請留意課程公告，並依教師或助教指定的期限提出。
